# sieve-NG fork notice

sieve-NG is a modified fork of the Sieve project created and maintained by
[Thomas Schmid](https://github.com/thsmi) and its contributors:

https://github.com/thsmi/sieve

Modern Thunderbird connectivity is based on the TCPSocket solution contributed
by [heeen](https://github.com/heeen) in
[upstream pull request #1145](https://github.com/thsmi/sieve/pull/1145). The
related hostname and username compatibility fix was contributed by the same
author in [pull request #1144](https://github.com/thsmi/sieve/pull/1144).

The fork was created in 2026 to maintain compatibility with current versions
of Thunderbird. It is independently maintained and is not an official release
of the upstream project.

The original copyright notices, contributor history and AGPLv3 license are
retained. Changes made for sieve-NG are documented through the Git history.
